# Máquina de Perfumes — versão de teste do app

App que monta um perfume a partir de algumas perguntas e dosa os ingredientes da máquina. Funciona **sem internet** depois da primeira abertura (PWA).

- **Não é o produto final.** Os acordes de autoria própria ainda são hipóteses: ninguém os cheirou.
- **Nada sai do aparelho.** Não há servidor nem conta; as receitas ficam no navegador de quem usa.
- Para instalar: abrir o endereço do app no celular e usar "Adicionar à tela inicial".

Gerado por `exportar_pwa.py --publicar` do projeto principal (só os arquivos de hospedagem).
